# Floating Phrases

[![CI](https://github.com/GitHubOfWangXu/FloatingPhrases/actions/workflows/ci.yml/badge.svg)](https://github.com/GitHubOfWangXu/FloatingPhrases/actions/workflows/ci.yml)

把每天反复找的东西，放到桌面边上。

Floating Phrases 是一个 Windows 悬浮工具：常用回复点一下复制，项目文件夹、Markdown 文档和软件集中打开，临时待办随手记。不用时贴边收起，用时悬停展开。日常数据保存在本机，无需注册应用账号；可选的英文翻译需要联网并自行配置所选服务的 API Key。

适合经常重复回复、切换项目目录，以及希望随手记录待办的 Windows 用户。支持搜索、置顶与拖动排序；这是一个轻量桌面入口，不是跨设备同步或团队任务管理工具。

## 英文翻译

1. 选中英文并按 `Ctrl+C`，再按 `Ctrl+Alt+Y`；也可点击标题栏“翻译”或托盘菜单“翻译剪贴板英文”。
2. 首次使用时，在翻译窗口选择服务，展开“所选服务的 API Key 配置”并填写对应密钥：Qwen 使用阿里云百炼**北京地域、按量付费** API Key；GLM Coding 使用智谱 **Coding 套餐 API Key**。不要将密钥发到聊天、Issue 或仓库。
3. 点击“翻译 / 重试”，查看英文原文与中文译文。后续使用快捷键会直接翻译新复制的文本；“复制译文”主动写入剪贴板，`Esc` 关闭窗口。

也可直接在“英文原文”框输入、粘贴和修改多行英文，再点击“翻译 / 重试”。修改原文会取消旧请求的等待并清除旧译文，不会自动发起新的翻译。

软件会记住上次选择的服务。切换服务保留原文、清除旧译文，不自动发送请求；密钥框存在未保存输入时会阻止切换，请先保存或清空输入。

采用 `qwen-mt-flash`，通过北京地域的 [DashScope 官方接口](https://help.aliyun.com/zh/model-studio/base-url) 发起英译中请求。需要在百炼控制台开通模型权限并保证可用额度，费用按 [官方价格](https://help.aliyun.com/zh/model-studio/model-pricing) 结算。每次最多 12,000 个字符，不自动截断；超时或失败保留原文，不自动重试计费请求。

GLM Coding 通道直接请求 `https://open.bigmodel.cn/api/coding/paas/v4/chat/completions`，使用 `glm-5.3-flash` 和英译中提示词，不需要启动 ZCode 或其他应用。请求使用 FloatingPhrases 自身身份，不复用其他应用的登录令牌或网关。端点和模型参见[官方接入指南](https://docs.bigmodel.cn/cn/coding-plan/tool/others)与[模型说明](https://docs.bigmodel.cn/cn/coding-plan/latest-model)。套餐资格与客户端使用范围由智谱服务端校验，**本软件不保证自建客户端可以使用套餐额度**；官方支持范围请以[官方 FAQ](https://docs.bigmodel.cn/cn/coding-plan/faq)为准。失败不会自动切换到智谱普通 API、Qwen 或其他收费通道。

只有点击翻译入口、按翻译快捷键或手动重试时才发送文本；不持续监听剪贴板，不模拟复制，不读取整篇文档，不保存翻译历史，也不自动替换剪贴板。请勿主动提交不适合发送到云端的内容。取消等待或关闭窗口无法撤回已提交的云端请求。

Qwen 密钥继续保存在 `%APPDATA%\FloatingPhrases\translation-key.bin`；GLM Coding 密钥保存在同目录的 `translation-key.bin.glm-coding`，服务选择保存在 `translation-key.bin.provider`。均使用 Windows DPAPI 当前用户加密，更新时保留加密的 `.bak` 恢复文件，不迁移或覆盖已有 Qwen 密钥。保存密钥或切换服务本身不会联网或验证密钥有效性；损坏文件不会被自动清理。密钥不能直接跨用户或跨设备复制使用，请在新设备重新配置。现有 JSON 数据格式不变。截图按钮仍只截图，本期不包含 OCR。

## 系统要求

- Windows 10 或 Windows 11
- 从源码构建需要 .NET 8 SDK
- 运行框架依赖版本需要 .NET 8 Desktop Runtime 和 ASP.NET Core 8 Runtime；自包含发布版无需另装运行时

## 快速开始

1. 从 GitHub Releases 下载并解压 Windows 构建，或者按下方命令从源码构建。
2. 运行 `FloatingPhrases.exe`。
3. 窗口默认显示在屏幕右侧并保持置顶，可以拖动标题栏调整位置。
4. 使用 `Ctrl + Alt + Space` 随时显示或隐藏窗口，使用 `Ctrl + Alt + T` 开启或关闭鼠标穿透。
5. 点击标题栏的“截图”，拖拽选择当前屏幕区域，截图会自动复制到剪贴板；按 `Esc` 取消。
6. 点击右上角的“—”会隐藏到系统托盘；双击托盘图标可以重新显示。
7. 要彻底结束程序，右键托盘图标并选择“退出”。直接关闭窗口只会隐藏程序。

标准 Release 构建的程序位于：

```text
bin\Release\net8.0-windows\FloatingPhrases.exe
```

## 常用句子

- 点击短语卡片：将完整内容复制到剪贴板。
- 点击“新增”：填写标题、分组和内容；标题不填时使用内容第一行。
- 点击卡片右侧的“改”：修改短语。
- 点击卡片右侧的“删”：确认后删除短语。
- 按住卡片拖到另一条短语的上半部或下半部：调整显示顺序并自动保存。
- 在搜索框输入文字：同时搜索标题、分组和内容。
- 勾选“置顶这条短语”：让它排在普通短语之前。

复制后到目标程序中按 `Ctrl + V` 粘贴。短语支持多行文本，并保留首尾空格。

## 本地文件夹

在“文件”页点击“文件夹”标签，继续使用原有文件夹快捷入口。“文件夹”和“Markdown”并排显示，单击即可切换。

- 点击文件夹卡片：使用 Windows 资源管理器打开该目录。
- 点击“新增”：填写名称并通过“选择…”挑选本地文件夹。
- 名称不填时自动使用文件夹名称。
- 点击卡片右侧的“改”或“删”：修改或删除快捷入口，不会删除真实文件夹。
- 按住卡片拖到另一个文件夹的上半部或下半部：调整显示顺序并自动保存。
- 搜索框同时搜索名称和完整路径。
- 勾选“置顶这个文件夹”：让它排在普通文件夹之前。

保存时文件夹必须真实存在。如果文件夹后来被移动或删除，点击卡片会提示修改或删除快捷入口。

置顶项始终显示在普通项之前。拖动排序需要在同一区间内进行：置顶项之间可以互相排序，普通项之间可以互相排序。

## Markdown 文档

- 在“文件”页切换到“Markdown”，点击“新增”选择一个或多个 `.md` / `.markdown` 文件，也可以把文件从资源管理器拖入列表；重复文件会跳过。
- 点击卡片用所选编辑器打开原文件。新入口默认使用 Obsidian；点击“改”可为每个文件指定 Obsidian 或 VS Code，文件位置不影响选择，无需加入知识库或安装额外插件。
- 右键卡片可临时选择 VS Code 或 Obsidian，也可打开所在文件夹、复制路径；临时选择不改变已保存的打开方式。
- 点击“改”编辑名称、路径、置顶状态和默认打开方式。搜索匹配名称与路径；按住卡片拖动可在同一置顶状态内调整顺序。
- 点击“删”只删除快捷入口，不删除 Markdown 原文件。文件被移动或删除后，打开时会提示重新选择。
- 文档正文由外部编辑器直接保存到原目录，Floating Phrases 不保存正文副本。保存快捷入口失败时保留原列表和当前编辑内容。

VS Code 需安装正式版；程序会从 PATH、`vscode` 协议或常规安装目录查找。Obsidian 库外文件打开需要 1.14 或更高版本及最新安装程序，请安装并运行一次后重新启动 Floating Phrases。程序通过注册的安装入口直接传入原文件路径。

旧入口的“自动”、缺省或未知打开方式兼容为 Obsidian；原先明确选择的 VS Code 或 Obsidian 保持不变。读取时不改写数据，下次保存时写入明确选项，并在 `.bak` 中保留上一次文件。

VS Code 原生支持 Markdown 预览：按 `Ctrl + Shift + V` 切换预览；先按 `Ctrl + K` 再按 `V` 打开旁侧预览。包含 Wiki 链接或嵌入的知识库笔记适合在 Obsidian 查看；移动和重命名笔记优先在 Obsidian 内进行。

## 手机扫码互传

在“文件”页选择“手机互传”。手机无需安装 App，也无需注册账号；文件直接通过局域网传输。

1. 电脑和手机连接同一路由器的局域网，或连接同一个热点；电脑也可以使用网线。
2. 选择手机所在网络对应的电脑网卡，点击“开启互传”。手机用相机或扫一扫打开二维码链接；微信等内置浏览器若不能选择或下载文件，请改用系统浏览器。
3. 手机网页选择照片或文件，点击“发送到电脑”；支持多选、上传进度和取消，文件逐个发送。
4. 电脑点击“添加文件”或拖入文件，网页会自动刷新分享列表；手机点击“下载”即可保存。添加文件也会自动开启互传。
5. 接收文件保存在 Windows 下载目录下的 `FloatingPhrases` 文件夹，可点击“打开接收目录”。同名文件另存为 `名称 (1).扩展名`，不覆盖原文件；上传未完成时不显示为成功。
6. 用完点击“关闭互传”；旧链接立即失效，再次开启需要重新扫码。隐藏到托盘会继续互传；从托盘退出程序会关闭服务。移除分享项只停止分享，不删除原文件。

单个文件上限为 2 GiB。上传期间保持网页打开，不要锁屏；手机的下载位置由浏览器决定。没有接收确认弹窗，拥有当前二维码链接的设备可以向专用接收目录上传；不会自动打开或执行收到的文件。

二维码携带随机临时访问令牌，只分享电脑明确选中的文件，不开放整盘浏览。服务只绑定所选的局域网 IPv4 地址；网页和二维码由本机生成，不访问第三方站点。浏览器连接使用 HTTP，请仅在可信的局域网使用，不公开转发二维码或链接。

首次开启时 Windows 防火墙可能询问是否允许访问，按当前可信网络允许即可；应用不会自动修改防火墙。如果扫码打不开，检查网卡选择、双方是否在同一局域网、VPN 是否阻断本地流量，以及访客 Wi-Fi 是否隔离设备，然后刷新网络并重新开启互传。

## 本地软件

- 点击软件卡片：启动对应程序或 Windows 快捷方式。
- 点击“新增”：手工选择 `.exe`、`.com`、`.bat`、`.cmd`、`.msi` 或 `.lnk` 文件，并设置名称、分类和是否置顶；默认归入“自定义”，选择文件不会改动已选分类。
- 点击“导入桌面”：扫描当前用户桌面和公共桌面，只导入目标为本地程序的快捷方式；文件夹快捷方式和网页快捷方式不会导入。
- 导入只追加新路径，按快捷方式路径跳过已有项目；不会覆盖自定义软件的名称、分类、置顶状态和顺序，再次导入不会重复添加。
- 点击卡片右侧的“改”或“删”：修改或删除启动入口，不会卸载程序，也不会删除原始快捷方式。
- 搜索框同时搜索名称、分类和路径；分类下拉框可以只查看某一类软件。
- 按住卡片拖到同分类、同置顶状态的另一个软件上：调整显示顺序并自动保存。

分类下拉包含“自定义”和七个原有分类：开发工具、办公沟通、浏览阅读、文件网络、远程连接、系统工具和其他。选择“自定义”可集中查看手动添加的软件；已有入口可点击“改”将分类设为“自定义”。桌面导入会根据快捷方式名称和目标程序给出初始分类，不会自动归入“自定义”；分类不准确时可以点击“改”手工调整。

软件入口保存的是所选程序或 `.lnk` 快捷方式的路径。如果程序被卸载、移动，或者桌面快捷方式被删除，点击时会提示修改或删除入口。

## 终端命令

- 打开“命令”页并点击“新增”，填写名称、命令内容、终端类型和工作目录。已有短语内容可复制到命令编辑框。
- PowerShell 使用 Windows 自带的 Windows PowerShell，支持中文、引号和多行命令；CMD 支持单行命令，可用 `&&` 或 `&` 连接。两种终端的语法不同，请按所选类型填写。
- 工作目录可通过“选择”按钮指定，也支持 `%USERPROFILE%` 等环境变量；留空时使用当前用户目录。
- 点击“运行”后，在确认窗口核对完整命令及实际工作目录，再点击“运行”启动终端。执行后终端保持打开，便于查看输出；若命令自身包含 `exit`，终端会退出。
- 支持搜索、编辑、复制和删除命令入口。保存、搜索、复制及程序启动均不会执行命令；保存失败会保留原列表。

例如，名称填“查看项目状态”，工作目录选择你的项目文件夹，命令填 `git status`。之后无需手动复制和打开终端。

命令以当前用户权限运行，应用不请求管理员权限、不绕过执行策略。只保存和运行你信任的命令；命令自身可能访问网络或修改文件。命令记录保存在独立的 `commands.json`，不改变已有短语和其他数据格式。

## 电脑状态与系统管理

打开最后一个“电脑”标签，可查看 CPU、物理内存、本地固定磁盘空间和已连接网卡的实时速率。原有短语、文件、软件、待办和命令功能保持原有页序。

- 本页可见时每 2 秒在后台采样；切换页面、隐藏到托盘或贴边收起后暂停，再次展开时重新采样。CPU 和网速需要相邻两次读数，首次显示“采样中…”，约 2 秒后显示速率；读取失败显示不可用或错误提示。
- CPU 使用率按 Windows 系统计时增量计算，内核时间包含空闲时间；超过 64 个逻辑处理器时统计当前处理器组。内存沿用系统物理内存口径，磁盘显示当前用户可用空间和总容量（GiB）。
- 网络按已连接网卡分别显示接收和发送速率（B/s、KiB/s、MiB/s），排除回环和隧道接口。虚拟网卡可能同时显示，避免将各网卡相加当作互联网总速率；有连接不代表能访问互联网。断线、新连接和计数器重置后重新采样。
- 系统管理入口包括任务管理器、资源监视器、声音、显示、网络、电源与睡眠、存储、已安装应用、启动应用、Windows 更新和系统服务。按钮只请求打开对应 Windows 窗口，不执行终端命令、不自动更新或卸载软件，也不自动提权；部分入口会受 Windows 版本或组织策略限制。

此页使用 Windows/.NET 原生接口，无需额外安装工具或管理员权限，不联网获取数据，不新增用户数据文件。CPU、磁盘和网络采样不影响底栏与贴边小块原有的内存显示。“电脑”页没有新增条目，标题栏的“＋”在本页禁用。

### 内存详情与进程控制

1. 点击“电脑”页内存卡片中的“查看占用程序”，打开详情窗口，查看系统已用和可用内存，以及程序名称、PID、驻留内存和专用提交。列表按驻留内存从高到低排列，可按名称或 PID 搜索；窗口可见时每 5 秒后台更新，也可手动刷新。
2. 驻留内存包含共享内存页，专用提交不是实际 RAM 占用；各进程之和不等于系统已用内存，系统还包含内核、驱动等占用。没有权限或已退出的进程会跳过并计数；无法核验启动时间的进程仍可查看，但不能直接结束。不会读取命令行、窗口正文或保存进程列表。
3. 选择普通进程后点击“结束所选进程”，核对程序名和 PID 后确认。强制结束可能丢失未保存内容并中断任务，建议先在程序内保存并正常退出。只结束所选进程，不结束子进程；实际结束前再次核验启动时间、当前用户和 Windows 关键进程标记。拒绝结束应用自身、系统关键进程、系统服务、其他用户或会话的进程，不自动提权或绕过拒绝访问。操作失败会保留原因，请刷新后确认结果。
4. 要管理 Windows 服务，点击电脑页的“系统服务”，在 Windows 服务管理器中查看和停止；停止服务不等于禁用开机启动，Floating Phrases 不自动改动服务设置。

## 标题栏操作

- 模式下拉框：在普通、悬浮、穿透三种模式之间切换。
- 透明度滑块：设置悬浮闲置或穿透时的透明度，可调范围为 20%–90%。
- “＋”：根据当前页面新增短语、文件夹、Markdown、软件、命令或输入待办；托盘菜单也提供相应新增入口。
- “截图”：框选当前屏幕区域，并将截图复制到剪贴板。
- “翻译”：翻译剪贴板中的英文，也可按 `Ctrl+Alt+Y`。
- “—”：隐藏到系统托盘。

### 三种窗口模式

| 模式 | 行为 |
| --- | --- |
| 普通 | 不置顶，保持 100% 不透明，可以正常操作 |
| 悬浮 | 保持置顶；鼠标移入恢复 100%，移开约 0.65 秒后淡化到设定透明度 |
| 穿透 | 保持置顶并使用设定透明度，鼠标点击会落到后方程序 |

进入穿透模式后无法直接点击窗口控件，这是预期行为。按 `Ctrl + Alt + T`，或右键托盘图标选择“恢复可操作”，即可返回悬浮模式。

窗口模式和透明度会自动保存。当前版本仍不会记住窗口位置，也不能自定义快捷键。

### 贴边收起

- 在“悬浮”模式下，拖动标题栏靠近当前显示器工作区的任一边缘（16 个逻辑像素内）时立即吸附；仅靠近时，鼠标移开约 650 毫秒后自动收起。继续向屏幕外拖动并松手，会直接贴边收起，不再留下半个面板。
- 收起后仅保留约 44×64 的侧边块（顶部和底部为 64×40），显示当前系统内存占用百分比；原生窗口裁剪同时限制显示和点击范围，原面板区域不会再挡住后面的鼠标操作。边块随屏幕缩放比例调整。
- 在边签上停留约 250 毫秒或直接点击即可展开。快速经过不会立即弹出；展开后移开鼠标会再次收起。
- 展开和收起使用约 220 毫秒的轻微滑动及淡入淡出，整个过程（包括起止帧）保持原生窗口尺寸和边签位置不变，避免透明窗口重建画面引起抖动或闪烁；拖动、切换模式或隐藏窗口会安全结束过渡。贴边时暂停闲置淡化，拖离边缘后恢复原透明度规则。
- 收起的小块也可直接按住拖动，沿边移动保持收起，拖离边缘后展开；展开时拖动标题栏离开边缘即可取消吸附。底边吸附在工作区底部，小块位于任务栏上方。
- 编辑弹窗、下拉选择和按住鼠标拖动期间暂停收起；使用键盘输入也会延后收起。
- 收起时按 `Ctrl + Alt + Space` 或使用托盘“显示 / 隐藏”会直接展开；普通和穿透模式保持完整面板，`Ctrl + Alt + T` 仍可切换穿透。

贴边状态仅在本次运行中保留，不修改已有数据或设置文件格式。

### 系统内存占用

窗口底栏和贴边小块每 2 秒刷新系统物理内存占用百分比；悬停提示显示已用和总量（GiB）。占用按“总物理内存减去可用物理内存”计算，读取失败时显示 `--`。隐藏到托盘后暂停刷新，再次显示时立即更新。此功能只读取本机 Windows 内存状态，无需管理员权限，不写入数据文件。

### 待办清单

- 在“待办清单”输入内容后点击“添加”或按 Enter；点击“改”可编辑，取消按钮或 Escape 可放弃编辑。
- 添加或编辑时可填写 0–100 的整数进度，清单中显示百分比；100% 自动标记完成。勾选完成会设为 100%，再次点击恢复未完成并重置为 0%；已完成项显示删除线并排在后面。
- 点击“复制清单”复制当前搜索和筛选结果，每条仅包含文字和进度（例如 `整理今日计划 50%`），不带 Markdown 复选框标记，可直接粘贴到工作日志。
- 支持内容搜索以及全部、未完成、已完成筛选，底部显示完成数量。
- 点击“删”后可用“撤销删除”恢复最近删除的一项；撤销记录仅在本次运行有效。
- 每次成功修改立即保存到独立的 `todos.json`，重启后保留；保存失败会保留原列表及当前输入并提示错误。

## 配置和数据位置

所有用户数据保存在：

```text
%APPDATA%\FloatingPhrases
```

通常对应：

```text
C:\Users\你的用户名\AppData\Roaming\FloatingPhrases
```

| 文件 | 内容 |
| --- | --- |
| `phrases.json` | 常用句子 |
| `folders.json` | 文件夹快捷入口 |
| `documents.json` | Markdown 快捷入口、置顶、顺序与默认打开方式；不包含正文 |
| `settings.json` | 窗口模式和闲置透明度 |
| `apps.json` | 本地软件快捷入口、分类和顺序 |
| `todos.json` | 待办内容、进度百分比和完成状态；旧数据按完成状态兼容为 0% 或 100% |
| `commands.json` | 命令名称、原始内容、终端类型和工作目录 |
| `commands.json.bak` | 上一次保存前的命令备份 |
| `todos.json.bak` | 上一次保存前的待办备份 |
| `phrases.json.bak` | 上一次保存前的短语备份 |
| `folders.json.bak` | 上一次保存前的文件夹备份 |
| `documents.json.bak` | 上一次保存前的 Markdown 入口备份 |
| `settings.json.bak` | 上一次保存前的窗口设置备份 |
| `apps.json.bak` | 上一次保存前的软件入口备份 |
| `*.corrupt-时间.json` | 自动保留的损坏数据文件 |

这些 JSON 文件都是明文，请勿保存密码、Token、私钥或其他敏感信息。

### 手工备份

退出程序后，复制整个 `%APPDATA%\FloatingPhrases` 文件夹即可。恢复时退出程序，再将备份文件夹复制回原位置。

### 使用 `.bak` 恢复

1. 从托盘菜单退出程序。
2. 先把当前 `.json` 文件复制到其他位置留档。
3. 将对应的 `.json.bak` 复制一份，并改名为 `.json`。
4. 重新启动程序检查数据。

## 界面展示与布局检查

标题与操作工具分成两行，六个标签等宽显示；搜索框带输入提示。可用自检入口导出通用示例界面，不启动主窗口、不读取用户数据、不注册快捷键：

```powershell
dotnet build .\FloatingPhrases.SelfTest\FloatingPhrases.SelfTest.csproj -c Release
dotnet .\FloatingPhrases.SelfTest\bin\Release\net8.0-windows\FloatingPhrases.SelfTest.dll --ui-export . bin\ui-preview
```

导出覆盖 370/430 逻辑像素宽度、96/144/192 DPI、六个页面与文件页的 Markdown 列表、互传关闭和开启样例，以及电脑状态和管理入口的布局。此入口检查布局，不代替手机扫码、软件启动或贴边交互的运行验收。

## 构建和自检

需要 .NET 8 SDK。互传服务使用 .NET 的 ASP.NET Core/Kestrel；二维码使用 QRCoder（MIT），第三方声明随程序分发。

电脑页自检覆盖 CPU 与网络速率计算、计数器回退、不可用状态、真实 Windows 采样，以及各系统管理按钮的真实控件事件；启动动作由测试回调检查，不实际打开系统管理窗口。可在构建后使用 `--computer-only` 单独运行这一组检查。

内存详情自检使用通用样例核对排序、搜索、确认与取消、受保护目标拒绝和失败反馈，真实结束检查仅使用自建临时子进程，并验证启动时间变化后拒绝结束。`--memory-only` 可单独运行；布局导出另含详情窗口在 560/700 宽度、96/144/192 DPI 下的通用样例，不导出真实进程数据。

```powershell
dotnet build .\FloatingPhrases.csproj -c Release
dotnet run --project .\FloatingPhrases.SelfTest\FloatingPhrases.SelfTest.csproj -c Release
```

自检覆盖短语、文件夹、软件入口和窗口设置的保存读取，软件分类归一化、透明度安全范围、拖动顺序、置顶状态、损坏 JSON 备份恢复，以及多行短语的空白字符保留。

Markdown 自检使用临时文件和真实控件事件，覆盖添加去重、搜索、编辑与取消、删除、保存失败时列表一致性、重新读取、旧打开方式兼容、默认 Obsidian 与每个文件的明确选择、右键临时覆盖、库外文件打开参数、缺失文件和原文保留；启动动作通过注入回调检查，不实际打开外部编辑器或读取个人笔记。

待办自检使用临时目录和真实控件事件，覆盖新增、编辑与取消、完成与恢复、搜索筛选、删除与撤销、重新加载，以及保存失败时的界面一致性和损坏文件恢复。

命令自检覆盖独立存储、备份与损坏文件留档、确认与取消、搜索和编辑、保存失败的一致性，以及真实 PowerShell/CMD 对中文、引号和工作目录的处理。测试使用临时目录和无害命令，不读取或执行用户保存的命令。可用 `dotnet .\FloatingPhrases.SelfTest\bin\Release\net8.0-windows\FloatingPhrases.SelfTest.dll --command-terminal-smoke` 检查可见终端启动，测试写入临时标记后自动退出。

互传自检仅使用 loopback 和通用临时文件，覆盖访问令牌、Host/Origin 校验、只分享选中文件、非法文件名和超限拒绝、中文同名保存、收发字节一致、中断清理、关闭失效和重新开启。`--transfer-only` 可单独执行；`--transfer-browser <临时目录>` 可启动隔离的网页验收入口，按 Ctrl+C 关闭，不使用个人数据。

贴边回归还检查完整过渡的窗口尺寸、原生裁剪和点击区域，并向隐藏测试窗口发送 `WM_MOVING`，验证四边实时吸附、越界松手收起以及拖离吸附范围。可在桌面空闲时运行可见录帧验收（将 `Right` 替换为 `Left` 或 `Top` 检查其他方向）：

```powershell
dotnet .\FloatingPhrases.SelfTest\bin\Release\net8.0-windows\FloatingPhrases.SelfTest.dll --dock-visual bin\dock-visual\right Right
```

该入口使用通用示例窗口，自动录下展开/收起画面，检查亮度反向跳变，并输出 PNG、时间记录和 `audit.json`；不读取用户数据。桌面遮挡或采样不足也可能导致验收失败，应结合输出画面检查。另有 `--app-visual` 可启动读取本机数据的真实主窗口并临时显示任务栏入口，方便桌面工具定位；该实例会在 90 秒后正常退出。

## 隐私与安全

Floating Phrases 在本机运行，不需要账号或云服务器。仅手动开启手机互传时监听所选局域网地址，分享文件和接收内容不经过第三方服务。用户数据保存在 `%APPDATA%\FloatingPhrases`，不会作为项目文件上传。本版本不再提供其他应用文本选区采集或飞书复制功能，也不注册 Ctrl + Alt + C。旧版复制历史文件不会自动删除。

发现安全问题时，请按 [安全策略](SECURITY.md) 使用 GitHub 私密漏洞报告，不要在公开 Issue 中附带个人数据。

## 常见问题

### `Ctrl + Alt + Space` 没有反应

快捷键可能已被其他程序占用。程序底部会显示冲突提示；退出占用快捷键的程序后重新启动 Floating Phrases。`Ctrl + Alt + T` 冲突时仍可使用托盘菜单退出穿透模式。

### 窗口变透明后无法点击

如果当前是穿透模式，这是正常行为。按 `Ctrl + Alt + T`，或者右键托盘图标选择“恢复可操作”。悬浮模式只是闲置淡化，鼠标移入后会自动恢复到 100%。

### 构建提示 `FloatingPhrases.exe` 正在被占用

旧版本仍在托盘中运行。右键托盘图标选择“退出”，然后重新构建。需要继续使用当前程序时，可以先在独立输出目录构建和自检，完成后再同步运行目录。

### 更新功能后，开机启动的还是旧版本

开机自启运行的是 Windows 自启入口指向的程序；构建到其他目录或更新 Git 源码不会自动更新该程序。

本项目在已配置自启的开发设备上交付功能更新时，会同时更新实际自启目标并重启验证。先备份旧程序，在没有未保存编辑或进行中的文件传输时同步完整运行文件，再从原自启入口启动；交付前核对进程路径及程序文件的 SHA-256 与已验证构建一致。标准运行目录为 `bin\Release\net8.0-windows`，独立验收目录不作为自启入口。更新失败时恢复备份，用户数据保持原目录。

### 点击文件夹后提示目录不存在

真实目录已经被移动、重命名或删除。点击卡片右侧的“改”选择新位置，或者删除该快捷入口。删除快捷入口不会删除磁盘上的文件。

### 桌面软件没有全部导入

程序只导入目标为本地可执行程序的 Windows 快捷方式。指向文件夹的快捷方式、网页 `.url`、目标已失效的快捷方式会被忽略；需要时可以点击“新增”手工选择程序或快捷方式。

### 点击软件后提示入口不存在

如果保存的是桌面 `.lnk`，桌面快捷方式可能已被移动或删除；如果保存的是程序本体，程序可能已卸载或迁移。点击“改”重新选择即可，删除入口不会卸载软件。

### 点击右上角“—”后找不到程序

程序只是隐藏到了 Windows 系统托盘。双击托盘图标即可重新显示。
